# Pocket Sera Docs

This directory contains the Pocket Sera documentation site.

The site uses Astro Starlight.

Use `pnpm docs:dev` to run the site locally.

Use `pnpm docs:build` to build static files.

The production build writes files to `dist/public/doc`.

Vercel serves this folder at `https://pocket-sera.com/doc`.

Do not place secrets in this site.
