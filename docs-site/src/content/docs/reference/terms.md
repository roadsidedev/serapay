---
title: Terms
description: Read key Pocket Sera and Sera platform terms.
---

| Term | Meaning |
| --- | --- |
| Pocket Sera | The wallet and Mini App host application. |
| Pocket Mini App | A public web application listed by Pocket Sera. |
| Dev Console | The Pocket Sera developer staging, submission, and review surface. |
| Manifest | Public JSON metadata for a Pocket Mini App. |
| Launch URL | The public URL that opens a Pocket Mini App. |
| Permission | A declared Mini App capability need. |
| Sera | The stablecoin service layer used for supported account actions. |
| Sera Vault | Sera balance space for supported liquidity and trading actions. |
| Permit | An EIP-2612 token approval signature. |
| Quote | A time-limited Sera swap instruction. |
| Settlement | The final confirmed state of a transaction or order. |
| Raw amount | An integer token amount before decimal formatting. |
