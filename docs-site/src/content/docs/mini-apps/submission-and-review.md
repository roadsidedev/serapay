---
title: Submission And Review
description: Submit a Pocket Mini App and prepare it for owner review.
---

Submit a Mini App from the Dev Console.

You must sign in before you submit.

## Submission fields

| Field | Requirement |
| --- | --- |
| Name | Match the manifest name. |
| Description | Explain the user value and action. |
| Logo URL | Use a public image URL. |
| Launch URL | Use a public Mini App URL. |
| Manifest URL | Use a public JSON URL. |
| Developer identity | Match the manifest developer value. |
| Category | Select one supported category. |
| Version | Match the manifest version. |
| Permissions | Match the manifest permissions. |
| Supported currencies | List supported uppercase currency codes. |

## Validation

The host checks all submission URLs.

The host rejects private network URLs.

The host rejects localhost URLs during submission.

The host retrieves the manifest as JSON.

The host checks matching metadata.

The host creates a `pending` listing after validation passes.

## Review

An authorized owner reviews pending apps.

The owner can approve the app.

The owner can reject the app.

The owner can add a review note.

Only approved apps can appear in Explore.

## Review checklist

Keep all URLs available.

Use clear user-facing copy.

Use a stable mobile layout.

State permissions honestly.

Do not request secrets.

Do not hide financial actions.

Do not use deceptive content.
